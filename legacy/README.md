# Unsupported prototype archive

This directory preserves the repository's pre-2.0 orchestration, reasoning, UCF,
and LLM-provider prototypes for source-history continuity. It is not installed,
imported, tested, supported, or part of the Helix Core security/API contract.

The supported product lives in `src/helix_core`. Do not depend on modules in this
directory. They may be removed in a future release.
